# Portfolio Personnel - Bocar Ndiaye

Projet de portfolio web dynamique développé dans le cadre de la L3 TDSI (UCAD).
## 🚀 Technologies utilisées
- **Frontend :** HTML5, CSS3, JavaScript (ES6)
- **Backend :** PHP 8
- **Base de données :** MySQL (PDO)
- **Hébergement :** InfinityFree

## ✨ Fonctionnalités
- Interface responsive & multilingue (Français / Anglais)
- Formulaire de contact dynamique avec traitement PHP/AJAX
- Espace d'administration sécurisé par session PHP pour consulter/supprimer les messages
- Requêtes SQL préparées contre les injections SQL

## 🛠️ Installation en local
1. Cloner le dépôt : `git clone https://github.com/votre-username/mon-portfolio.git`
2. Importer le schéma de base de données dans phpMyAdmin.
3. Renommer `bd.php.example` en `bd.php` et ajuster vos identifiants MySQL.
4. Lancer via Apache/WampServer.
